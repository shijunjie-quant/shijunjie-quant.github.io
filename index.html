项目

L2 Engine

一个人的 A 股量化研究基础设施：分层数据湖、分钟级全市场回测引擎、GA 参数寻优，以及一个用于演示接线的双均线示例策略。

  • 三层数据湖（bronze 原始 → silver 清洗 → gold 业务就绪），bronze 层不可变，每层留血缘记录
  • 六维数据质量门禁：以 OHLC 逻辑、时间戳连续性等六个维度体检数据，曾揪出 pre_close 语义误用
  • 回测引擎零前向填充：停牌股无 bar、无成交——回测与实盘同一套成交语义
  • GA 参数寻优：walk-forward 训练/样本外切分；精英个体跨次复跑逐位一致，每次运行留 md5 审计锚
  • Docker 沙箱内可复现运行
  • 诚实口径：约 2 个月有效开发量，演进途中两次彻底重写；仓库只含研究框架与演示策略

l2-guardrails

L2 Engine 的 MCP 护栏层——把数据湖体检、宇宙查询、回测验证、沙箱写跑封装成七个带权限分级的工具，供 AI Agent 调用。

  • 七工具四级权限：工具面只暴露 L0（读）与 L1（沙箱写跑），L2/L3 由人发车与终审
  • 安全模型四原则：fail-closed（报错绝不静默成功）/ 双路径锁（resolve 解析后比对 parents 链，防前缀目录越界）/ 重活子进程化（不 import 引擎，互不连坐）/ 工具描述即契约
  • 沙箱三工具（write_file / run_full_backtest / read_log）：AI 生成的代码有受控写入口与 Docker 隔离执行环境，宿主主代码区对 AI 永远只读
  • 事故博物馆：v1 到 v3.4 的真实事故与修复记录
  • v3.4 修复前缀目录越界漏洞：startswith 匹配改为 parents 链比对
